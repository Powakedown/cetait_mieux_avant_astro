# C'était mieux avant

## Le projet
« C'était mieux avant ? » est une application web à vocation pédagogique. Elle propose une réponse visuelle et immédiate à la question que son titre pose : est-ce que c'était vraiment mieux avant ?

## Pour qui
Le grand public, pour une prise de conscience rapide et intuitive.
Les éducateurs et les étudiants, comme support visuel pour des cours d'histoire, de sociologie ou de sciences.
Les décideurs, comme outil de communication sur l'importance de préserver ou d'accélérer certains progrès.

## Nos engagements
Une pédagogie visuelle : comparer instantanément les époques et les domaines.
Des données tangibles, sourcées auprès de références fiables (Wikipédia, INSEE).
Une approche critique : chaque élément est accompagné d'annotations contextuelles expliquant son histoire.

# Contribuer

Ce projet est vivant, et vos contributions sont les bienvenues. Si vous souhaitez ajouter, corriger ou nuancer un élément du graphique, merci de le faire via une pull request.

## Nos attentes
Respect de l'histoire. Chaque avancée ou chaque recul mentionné doit être fidèle aux faits historiques, daté avec précision et rattaché à une source fiable (Wikipédia, INSEE, institutions académiques). L'objectif du projet est pédagogique : toute contribution doit servir la compréhension, jamais un parti pris.

Esprit constructif. Les échanges autour d'une contribution portent sur les faits et les sources, jamais sur les personnes. Une objection est toujours la bienvenue lorsqu'elle est argumentée et documentée.

Nuance et honnêteté. L'histoire est complexe : une avancée peut coexister avec des reculs, et certains sujets suscitent des interprétations divergentes. Nous encourageons les contributions qui rendent compte de cette complexité plutôt que celles qui simplifient à l'excès.

## En pratique
Avant d'ouvrir une pull request, prenez le temps de vérifier vos sources et d'expliquer, en quelques lignes, l'apport de votre contribution et son intérêt pédagogique. Les propositions seront examinées avec attention et bienveillance.

## 🚀 Project Structure

Inside of your Astro project, you'll see the following folders and files:

```text
/
├── public/
│   └── favicon.svg
├── src
│   ├── assets
│   │   └── astro.svg
│   ├── components
│   │   └── Welcome.astro
│   ├── layouts
│   │   └── Layout.astro
│   └── pages
│       └── index.astro
└── package.json
```

To learn more about the folder structure of an Astro project, refer to [our guide on project structure](https://docs.astro.build/en/basics/project-structure/).

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `yarn install`             | Installs dependencies                            |
| `yarn dev`             | Starts local dev server at `localhost:4321`      |
| `yarn build`           | Build your production site to `./dist/`          |
| `yarn preview`         | Preview your build locally, before deploying     |
| `yarn astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `yarn astro -- --help` | Get help using the Astro CLI                     |
